We keep the experimentation configuration the same as the original MAML work, for a fair comparison. Omniglot comprises 20 instances (drawn by 20 different people) of 1,623 characters from 50 alphabets. We follow the N-way Omniglot task setup, which was introduced by Vinyals et al. (2016), and also used in MAML (Finn et al., 2017). The N-way classification task is set up as follows: the model is shown K instances from N unseen classes, and then evaluated on some other instances from these N classes. To keep the procedure the same as MAML, we also randomly select 1,200 characters for training, and use the rest for testing. The network architecture follows the architecture used by Finn et al. (2017), and more implementation details are in the appendix A.
