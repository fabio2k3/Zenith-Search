# Zenith Search

Zenith is an intelligent PDF document search engine focused on retrieving information quickly and accurately from the actual content of texts.

Unlike traditional search engines, Zenith does not rely solely on exact keyword matches. It also understands the meaning of queries and combines semantic search with classical information retrieval techniques to deliver more relevant results.

The goal of the project is to allow users to write queries in natural language and obtain the most relevant PDF documents, ranked by relevance, so they can open and read them directly.

Zenith is designed as a foundation for a modern search system, useful for collections of articles, notes, research papers, or any set of PDF documents where manually finding information would be slow and inefficient.
